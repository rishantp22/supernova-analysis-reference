# 50AM nucleosynthesis audit: key findings

Audit date: 2026-10-18. Original datasets and group files are read-only throughout this investigation. This report summarizes completed population-wide measurements; the accompanying detailed report documents qualifications and remaining questions.

**Neither plotting dataset is currently validated for quantitative publication.** The new file faithfully reproduces its chunks, but this does not validate the trajectories, calculation provenance, or chunk extraction. The available legacy results also contain major coverage and solver-status problems.

1. **Located datasets.** The previous output is `/data/pyoung3/supernova_data/50Am/analysis/50Am_plotting.out` (748,723,480 bytes); the new output is `/scratch/rpraka15/50Am_plotting_all_isotopes.out` (1,766,352,794 bytes). Their unequal sizes establish that they are not byte-identical. A second legacy copy exists under `/data/pyoung3/gsvance/supernova_data/50Am/analysis/50Am_plotting.out`. No literal `50AmPlotting.out` was found in the inventoried group paths. `/scratch/rpraka15/final_chunks.out` is **1,438,981,268 bytes (1.44 GB decimal)**, consistent with the user's correction.
2. **Complete ID alignment.** The old file has 945,628 unique valid IDs. The new file has 937,228 rows, including malformed ID `y193`, leaving 937,227 valid IDs, all shared with the old file. No duplicate valid IDs were found. The chunks contain 937,229 unique IDs; new-file ID 23 is absent and ID 193 is malformed. No automatic repair was made.
3. **Legacy missing results were exported as zero.** All 668,118 old plotting IDs without a result in the eight available HDF5 files have zero in every exported nuclear-species column. Among shared valid IDs, 668,114 such particles represent 6.46772831413 solar masses; the 269,113 particles with raw legacy results represent 2.48935370249 solar masses. This is a verified major contributor to apparent abundance increases. Zero here must not be interpreted as a successful zero-yield calculation.
4. **Legacy solver flags require resolution.** Of 277,510 available legacy raw particle records, 277,507 store `looperror=1337`, and three store `100`. Available Burn source assigns 1337 on failure paths and saves abundances before checking the return code. The exact historical executable is not pinned; the particular failure branch for each particle is unresolved. The maximum raw mass-fraction sum is 1.38239028 (ID 157594).
5. **New candidate trajectory units are wrong.** All 943,900 corrected-archive trajectories, comprising 57,577,900 points, use snapshot iteration numbers as times. Their final printed time is 2000; the corresponding hydrodynamic time is 157,558 seconds under the source-recorded conversion. Every archived density agrees with native hydrodynamic density within export precision, while the header labels it g/cm³. The recorded conversion is 5.91182466035e-6. All ten inspected archived runtime prefixes show this unconverted-density behavior, and their last abundances reproduce the corresponding new plotting values within printed precision. This ties the unit problem to actual runs for these ten tracers; complete historical input revisions for every tracer remain unverified.
6. **Chunk grid and final assembly pass, but upstream consistency fails.** All 938 A chunks and 938 B chunks passed the complete ID/category/species grid audit, covering 624,194,514 records in each set. Every valid new plotting isotope value exactly equals the corresponding last-category A value. No final species-index mismatch was found. However, an independent census of 938,732 archived final EOC CSVs finds 8,456 finite abundance disagreements in 176 shared particles at relative tolerance 5.1e-6, absolute tolerance zero. Another 5,682 positive plotting cells have no finite archived final-X counterpart.
7. **Particle 7753 has approximately doubled abundances.** Its plotting selected-isotope sum is 1.97736906, compared with full archived final sum 1.00000085451. All 48 discrepant finite species have new/final ratios within about 8.3e-6 of two. For 54Fe, the archived final value is 0.525792049882292 and the plotting value is 1.05158. The chunk script sums by printed time and therefore can combine repeated time blocks; the original 7753 time series must be recovered before identifying the exact mechanism as proven.
8. **Output epochs and inventories differ.** The old plotting inventory has 65 nuclear-species columns including neutron; the new one has 223 including an entirely unavailable neutron column, with 222 numeric isotope columns. All 59 new elemental totals are `NA`. The raw legacy network contains 524 species. The inspected PRISM extent lists 13,396 potential species; the complete EOC archive actually contains 264 distinct species rows, of which 245 have any finite X. Larger export coverage, configured network extent, and actually represented species are distinct quantities. New chunk last times range from 0.936977 to 166,000 seconds; outputs cannot be assumed to describe one epoch.
9. **The physical-field agreement is copied metadata.** The new plotting exporter joins physical fields from the old plotting file by ID. Equal peak temperature, peak density, and reported progenitor Ye therefore do not prove equal nuclear-network trajectories. Independent checks validate the old physical fields against native SDF data within printed precision. In particular, the 495,014 zero Ye values among valid new IDs match zeros already in native `Y_el`; they are not attributed to the exporter's generic missing-record fallback. Native composition-derived Ye exposes their inconsistency, so these zeros cannot establish extremely neutron-rich ejecta.
10. **All archived seeds differ from native initial composition.** All 943,900 seeds differ in at least one shared native isotope and have composition-derived Ye lower by more than 1e-5. The native hydro network has only 20 physical species, so small differences may reflect model detail; large changes require a different explanation. For ID 917342, native X(1H)=0.66475999 and X(4He)=0.32527521, but the normalized PRISM seed has X(16O)=0.9450643. Its archived runtime starts with this oxygen-rich seed at T=0.000770219 GK. The seed producer/mapping is unresolved; the composition change occurs before burning.
11. **Legacy extraction also censors positive values.** Across 17,760,640 raw/plotting comparisons for 64 species, every cell either agrees within query precision or is a positive raw abundance exported as zero. There are 6,003,121 such censored cells, with omitted values approaching 1e-6. This is separate from missing-particle zero filling. The old 10Be plotting column is absent from the stored 524-species legacy network.

The direct legacy history audit also finds 242 inconsistent temperature/density points among 3,052,610 points, across 22 particles. All stored times align with original physical snapshot times; the remaining 3,052,368 temperature/density pairs match the native data and unit conversion. Full flags are retained in `tables/legacy_history_inconsistent_particles.csv`.

The full-population comparison uses `abs(new-old) <= rtol*abs(old)`, with `rtol=1e-5` for abundances, `1e-9` for copied physical fields, and `atol=0`. Exact equality is reported separately. Ratios and logarithms have no abundance floor; undefined cases remain unavailable. The archived density precision check additionally allows 5.1e-6 **native density units** absolute error, reflecting five printed decimal places, alongside relative tolerance 5.1e-6.

All-isotope statistics, yields, ID-aligned numerical arrays, closure checks, isotope number ratios, complete chunk receipts, EOC records, and PNG/PDF figures are saved in the sibling `tables/`, `provenance/`, and `figures/` directories. The inventory traversed 19,249,821 files and 1,956,345 directories across accessible Sarah Vierling and pyoung3 trees; `/home/pyoung3` was inaccessible, and symlinks were recorded without following them. Metadata enumeration is not a claim to have read every file's contents.

**Publication implication:** repeat Cr-only and Cr–Ti grain matching, Mg–Al and Ca–Ti–Cr correlations, and yields only after resolving legacy coverage/failures and validating corrected input histories, seed compositions, run identities, extraction, and epochs. No observational agreement or physical explanation for all isotope differences is established by this audit. No nuclear-network calculation has been launched.
